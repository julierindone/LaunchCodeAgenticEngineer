  ## Review Report: Export CSV Feature

  Reviewed against /workspace/docs/prd.md and the modified files in

  ### 1. Bugs / correctness issues

  **[Warning – Medium] `URL.revokeObjectURL` called synchronously, immediately
  after `link.click()`**
  In src/app.js:
  ```js
  link.click();
  document.body.removeChild(link);
  URL.revokeObjectURL(url);
  ```
  Revoking the object URL in the same tick as the click can, on some
  browsers/slow machines, invalidate the URL before the download has actually
  started, risking an empty/failed download. Fix: defer revocation, e.g.
  ```js
  link.click();
  document.body.removeChild(link);
  setTimeout(() => URL.revokeObjectURL(url), 0);
  ```

  **[Suggestion – Low] `tasksToCsv` has no input validation**
  `for (const task of tasks)` throws a TypeError on null/undefined/non-iterable
  input instead of failing predictably. Low risk today (only caller is
  `getTasks()`, always an array) but it's an unguarded public function. Suggest
  `export function tasksToCsv(tasks = []) { ... }` or an `Array.isArray` guard.

  **[Suggestion – Low] Missing/undefined field values stringify oddly**
  `escapeField` does `String(value)`, so a missing field becomes the literal
  text "undefined" rather than an empty cell. Not exercised by current static
  data; worth `value ?? ""` if the task model ever gains optional fields.

  **[Open question] "Visible" vs. "all" tasks**
  PRD says "download the currently visible task list." `handleExportCsvClick`
  reads from `getTasks()` directly rather than the rendered `#task-list` DOM.
  Equivalent today (no filtering UI exists), but would silently diverge if
  filtering is added later. Recommend a code comment or backlog note rather than
  a change now.

  ### 2. PRD compliance

  - Button near task list: yes — `#export-csv-btn` placed directly after

  row order/separation with 2+ tasks (the normal case — sample data has 3
  tasks). Add e.g.:

  ```js
    const csv = tasksToCsv([
      { id: 1, title: "A", status: "todo", dueDate: "2026-01-01", completed:
  false },
      { id: 2, title: "B", status: "done", dueDate: "2026-01-02", completed:
  true }
    ]);
    assert.equal(
      csv,
      "id,title,status,dueDate,completed\r\n" +
        "1,A,todo,2026-01-01,false\r\n" +
        "2,B,done,2026-01-02,true\r\n"
    );
  });
  ```

  **[Warning – Medium] No automated test for app.js at all**
  `attachExportCsvHandler`, `handleExportCsvClick`, Blob construction, the
